# Data Dictionary

The workbook contains **2,098 transactional sales records**.

| Field | Description |
|---|---|
| Date | Transaction date |
| Sales Rep | Sales representative associated with the transaction |
| Product | Product sold |
| Category | Product category |
| Quantity | Number of units sold |
| Unit Price | Selling price per unit |
| Cost Price | Cost per unit |
| Customer Type | Customer segment/type |
| Region | Geographic region |
| City | City associated with the transaction |
| Channel | Sales channel used for the transaction |
| Revenue | Sales revenue generated by the transaction |
| COGS | Cost of goods sold for the transaction |
| Profit | Revenue remaining after COGS |
| Date (Month Index) | Numeric month field used for ordering monthly analysis |
| Date (Month) | Month label used for reporting and dashboard analysis |

## Core Measures

**Revenue** represents the total sales value generated.

**COGS** represents the direct cost associated with the goods sold.

**Profit** is calculated conceptually as:

```text
Profit = Revenue - COGS
```

**Profit Margin** is calculated conceptually as:

```text
Profit Margin = Profit / Revenue
```

These measures form the basis of the KPI cards and performance comparisons shown in the dashboard.
